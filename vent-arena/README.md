# 出氣擂台 · EMC ARCADE

元宇宙的小遊戲，由元宇宙頁面及像素辦公室入口開啟。遊戲未串接登入、ERP、案件系統或正式 API；排行榜僅保存於本機瀏覽器，沒有多人連線與伺服器排行榜。前端純 HTML / CSS / Canvas / JavaScript，可獨立靜態託管。

## 本機執行

從專案根目錄執行：

```sh
node vent-arena/serve.mjs
```

開啟 `http://127.0.0.1:4180/vent-arena/`。也可使用其他靜態伺服器提供此資料夾。

## 玩法

- 玩家與陪練都能從目前 11 位角色中選擇；初始為 Machi 對 Noise。
- 點擊或按住擂台連打，空白鍵亦可；每次出手有最短間隔，避免同時多種輸入加速。
- 1–8 切換拳頭、藍白拖、平底鍋、鍵盤、奶油派、橡皮雞、雷擊、文件風暴。道具傷害、怒氣增量、效果不同。
- 陪練血量 300，擊倒後約 1.35 秒自動回滿，追加 100 分。
- 1.2 秒內接續出手累積連擊，每 10 連擊增加傷害得分倍率，最高 5 倍。
- 怒氣達 100% 可按 F 或必殺按鈕施放 150 傷害的「下班衝擊波」。
- 自由模式不限時；60 秒挑戰須手動開始，到時顯示結算。分頁隱藏時暫停挑戰，返回繼續。
- 三個自繪場景：茶水間、頂樓、會議室。音效預設關閉，開啟後使用 Web Audio 合成。
- 自訂台詞最多 40 字，以文字方式呈現，不渲染 HTML。
- 只有最高分儲存在 `localStorage.emcVentArenaBestV1`；其他進度重新整理會重置。localStorage 不可用時仍可遊玩。

## 素材與參考

11 張角色正面圖來自使用者提供的角色包，複製至 assets/，與 3D 展示頁沒有執行期依賴。場景及 UI 為此版本自行實作。

玩法參考使用者指定的 [HittingTheVillain](https://qooqqoor.github.io/HittingTheVillain/)，借鑑點擊／連打、道具切換、怒氣必殺、角色及場景設定的玩法概念；未複製該站原始碼、美術、音效或版面。

## 目前範圍

此版使用既有 2D 角色圖及 Canvas 動態變形，不含 3D 模型、逐格格鬥動畫、照片上傳、真實玩家對戰或雲端排行。虛擬陪練不會反擊。後續若整合辦公室，可將角色資料、開啟入口與成績事件獨立接線，不必修改此版既有辦公室資料。

`mobile-preview.html` 是 390px iframe 的版型檢查頁。遊戲入口為 index.html。
