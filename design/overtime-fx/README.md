# 加班特效視覺稿

直接開啟 v1.html、v2.html、v3.html，皆為無外部相依的單檔 Canvas 2D 動畫。三位角色的身高為 116、142、170 px，膚色及方／圓／寬頭型各異。特效不讀取臉部座標。

## 三版差異與建議

| 版本 | 光錐透明度 | 暗場峰值 | 鬼火尺寸 / H | 動態 |
| --- | --- | --- | --- | --- |
| v1 克制 | 0.13 | 0.12 | 0.105 | 兩簇，兩側輕飄、呼吸明滅 |
| v2 鬼屋 | 0.22 | 0.28 | 0.160 | 三簇，7 層拖尾、每簇 4 個微粒，光錐輕微閃爍 |
| v3 舞台 | 0.38 | 0.72 | 0.125 | 三簇慢速公轉，依深度分別畫在角色前後 |

建議正式遊戲預設採用 **v1**：能辨識加班狀態，長時間觀看較安靜，也適合多人同時出現。v2 適合鬼屋事件；v3 適合單人特寫。

## 色碼與尺寸

冷白光 #E8F4FF、地面光斑 #C5DBFF、藍焰 #586BFF、紫焰 #9565FF、冰藍內焰 #B9DEFF。光暈為 rgba(125,92,255,0.32)，暗場為 #030714。角色整身降飽和至 0.42，再以 #96B6E8、透明度 0.24 覆蓋不透明輪廓；保留不同膚色的辨識度。所有光效均無金黃配色。

以下皆以腳底中心為原點、H 為比例：

- 光錐頂端 y = -1.62H、半寬 0.05H，落地半寬 0.64H。
- 橢圓光斑半徑為 x = 0.67H、y = 0.1608H。
- 暗場中心 y = -0.55H，內外半徑 0.25H／1.05H，外緣淡出。
- v1／v2 火焰 x 約 ±0.39H，飄幅 0.035H；y 約 -0.43H，飄幅 0.045H。v2 第三簇額外 x +0.10H、y -0.34H。
- v2 拖尾間隔 180 ms，共 7 層、透明度遞減；粒子上升距離 0.30H，尺寸 0.012H。
- v3 軌道中心 (0, -0.48H)，半徑 (0.48H, 0.15H)，角速度 0.30 rad/s，一圈約 20.94 秒。

## 移植與播放

完整複製任一 HTML 內的 drawOvertimeFx(ctx, feetX, feetY, H, t, sprite)，即可獨立使用，無需頁面變數。H 預設 142 px，t 為毫秒，可傳 requestAnimationFrame 時間戳。sprite 是透明背景的角色 canvas，腳底置於底邊中心；寬度按原始寬高比縮放。函式同時繪製冷調角色與特效，應取代原角色繪製，避免重複。函式以 save／restore 保護 context。

整身冷調以 WeakMap 快取；角色 canvas 內容變動時，換用新 canvas，或呼叫 drawOvertimeFx._cache.delete(sprite) 更新。呼叫端每幀先重繪背景，避免光效累積。示範頁以 requestAnimationFrame 節流，每次繪製至少相隔 100 ms，最高約 10fps；可暫停動畫。背景、角色、火焰、光錐、粒子皆為程式繪製。

## v3b 修正說明

開啟 [v3b.html](v3b.html) 預覽「V3b · 最後的聚光（效能版）」。保留腳底錨點、全身冷調、三簇鬼火前後公轉、10fps requestAnimationFrame 節流與暫停控制。

- 光效以 H 四捨五入至 8px 的 bucket 與 light 旗標為 Map 快取 key。首次預畫暗角＋地面光斑合成圖、獨立光錐、含光暈的像素鬼火，後續以座標與 globalAlpha 控制，每人每幀共 6 次 drawImage，不再建立漸層或逐點畫火焰。
- 角色以 sprite 為 WeakMap key，尺寸變更自動重建，以 source-atop 疊冷藍灰 rgba(120,140,180,.32) 及 rgba(35,45,75,.12) 壓暗，不使用 ctx.filter。同尺寸內容變更可呼叫 drawOvertimeFx._cache.delete(sprite)。
- 第七個選填參數 opts = { light: false }：深色模式藍紫暗角峰值 .55、冷白光錐峰值 .38；白色模式暗角峰值 .22、淡藍光錐 rgba(150,180,255,.22)，地板 #ffffff、桌椅淺灰線稿。兩者皆有 1px 藍紫光錐邊線與地面橢圓光環，色彩 rgba(120,110,255,.55)。背景切換同步傳入 opts.light。
- 效能面板以 performance.now() 量測三人特效合計時間，顯示最近最多 60 次平均 ms，包含首次快取成本；切換背景重新累計。

HTML 為 UTF-8 單檔，無外部相依。
