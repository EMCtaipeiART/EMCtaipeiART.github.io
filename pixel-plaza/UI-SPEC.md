# 凱曜多元宇宙 3D 辦公室｜介面與設計規範

> 適用範圍：`pixel-plaza/index.html`（3D 像素辦公室）。**之後新增任何內容、介面、道具，都照這份規範做。**
> 最後更新：2026-10-31。數值對應 `index.html` 內 `<style>` 的 CSS 變數與常數；改了程式請一併更新這份文件。
>
> 設計來源：參考 PokéBonk（pokebonk.com）的介面語言。**我們只看得到它的載入／登入畫面**（糖果色漸層斜紋、粗描邊 Logo、傾斜的深色玻璃卡片、橘色斜紋標題、大按鈕、圓角膠囊）。戰鬥中的介面沒有看到，所以 HUD、圖鑑、等級這些是依同類遊戲的通用做法自行設計，不是對照它的實際畫面。

## 1. 設計原則

1. **主色系是綠色**（凱曜品牌色）。黃色只當點綴（星星、經驗條、Logo 第二個字），不當主色。**不要使用紅、紫、橘當大面積色塊。**
2. **圓、厚、粗描邊**：所有按鈕、卡片、標籤都是大圓角；文字與 Logo 有粗描邊；按鈕有「厚度」（底部深色邊）。
3. **玻璃卡片疊在場景上**：HUD 一律用深綠半透明玻璃，不用實心色塊，場景才不會被遮死。
4. **內容用繁體中文**，語氣輕鬆、有點辦公室幽默；數字與狀態要一眼看懂。
5. **只讀優先，寫入要確認**：預設只讀後端；任何會寫入真實後端的操作，第一次必須跳確認視窗（見 §9）。
6. **不遮臉、不遮電腦**：場景裡的物件不得壓在人物臉、電腦、投影機上（見 §8）。

- 對比：玻璃面板上文字一律白色；白色面板上文字用 `--r-ink`。不要在綠底上放綠字。

## 3. 字體

- 英數與標題：**Fredoka**（Google Fonts，權重 500／600／700）。
- 中文：**Noto Sans TC**（系統有就用，沒有就退回 `system-ui`）。
- 字體堆疊：`'Fredoka','Noto Sans TC',system-ui,sans-serif`。
- 粗細：一般文字 600；標題、按鈕、數字 700；不使用細體。
- 尺寸：Logo `clamp(54px,12vw,96px)`；卡片標題 19px；HUD 名字 16px；按鈕 14–19px；說明／註解 11–12px；浮動 +1 22px。
- **粗描邊字**（Logo、浮動文字）：`-webkit-text-stroke: 9px(Logo) / 5px(浮動) var(--ink); paint-order: stroke fill;`，Logo 再加 `filter: drop-shadow(0 6px 0 rgba(11,61,30,.55))`，整個旋轉 -3°。
- 場景裡的文字標籤（房間名、人物牌子）用 DOM 疊在畫面上，不畫進 3D，才清楚。

## 4. 形狀、間距、陰影、動態

- 圓角：卡片 22px；面板 18–22px；按鈕與標籤 999px（膠囊）；格子／道具框 14px。
- 邊線：玻璃元件 `2px solid var(--line)`；需要「粗框」的元件（提示框、投影小視窗）`3px solid var(--ink)`。
- 陰影：玻璃元件 `0 6–8px 14–20px rgba(4,36,18,.3)`；首頁卡片 `0 24px 50px rgba(4,36,18,.45)`；實心提示框用「硬陰影」`0 6px 0 rgba(11,61,30,.35)`。
- 主要按鈕（`.btn-red`，歷史命名，實際是綠色）：`linear-gradient(--cta1,--cta2)`、`border-bottom: 5px solid #0c6a26`、內側高光 `inset 0 2px 0 rgba(255,255,255,.35)`；hover 亮 8% 並上移 1px；按下下沉 2px、底邊縮成 3px。
- 次要按鈕（`.btn-ghost`、HUD 按鈕）：玻璃底、膠囊。
- 動態：hover 上移 2px（120ms）；面板進場 `translateY(6px)→0`（180ms）；浮動文字 1.3s 上飄 70px 淡出；載入的球旋轉 1.2s。尊重 `prefers-reduced-motion`（新增動態也要）。
- 斜紋、旋轉：首頁卡片 `rotate(-1.2deg)`；Logo `rotate(-3deg)`。其他元件**不要**旋轉。

- 其他裝飾圖示（轉盤的線條 SVG 已不使用）：不要混入第三種圖示風格。

## 7. 3D 場景規格

- 單位：版面圖 1 px = 0.03 世界單位（`U`）。**人物高 2.04**，桌子單張寬 3.15，人物：桌子 = 0.65，與 2D 版一致。
- 鏡頭：固定俯視，相對玩家 `(0, +10.9, +12.2)`，視角 45°；未登入時為固定全景。**不要改成更近**；人物大小以「比照 2D 版」為準。
- 人物與貼圖道具：**垂直站立**的 billboard（不後傾），高度乘 `STRETCH = 1/cos(atan(8.4/9.4))` 補償俯視縮短；人物 12 個面向（每 30°）。
- 家具與房間：用 **3D 方塊**做（低矮桌、椅、書櫃、馬桶…），不要用站立貼圖假裝桌子。
- 黑色外框：實心物件用「反向外殼」外框，粗度 `OUT_T = 0.04`（小圓件最低一個像素格）；外框物件放 layer 1。玻璃牆用粗線。**新增物件一律要有黑色外框。**
- 畫質：預設高清（用螢幕實際解析度）；`?px=1` 為復古低解析；`?outline=px` 為像素色塊黑線（實驗）。
- 碰撞：人物半徑 0.5；新增家具必須同時登記碰撞矩形，通道寬度要 ≥ 1.2 單位。
- 座位：每張椅子都是「座位」（`chairSeats`），按 E 可坐；新增椅子照 `chair3d` / `officeChair3d`。

## 8. 道具與內容規則

- **大小**：地上掉落物縮放 0.021 世界單位／像素、桌上遺落物 0.012、茶水檯零食高度 ×0.75；新增道具以「比現有最小的再小一點」為原則。
- **不得壓住**：道具、浮動物不可出現在人物的臉／身體前、電腦與投影機上、投影畫面範圍內（會議室 D 的地板投影）。已實作：畫面上落在人物範圍內就隱藏且不能點；遺落物避開投影機位置；掉落物避開地板投影區。**新增任何會「隨機出現」的物件，都要實作同樣的避讓。**
- 隨機規則：用「時段＋種子」計算（大家同一時段看到相同內容）：投影機 6 分鐘、便便 5 分鐘、掉落物 8 分鐘、遺落物 12 分鐘。沿用 `rng()`。
- 語錄、投影片：沿用 2D 版 `fun.js` 的資料（30 張投影片、27 種掉落物、25 種遺落物）；新增內容要放進同一份資料並給語錄。
- 像素素材：原始像素圖用最近鄰放大（`NearestFilter`）；Codex 畫的高解析素材用線性濾鏡。兩者不要混在同一個物件。

## 9. 資料與安全

- 出勤狀態：每 3 秒（背景 15 秒）讀 `pixelOfficeState`（只讀）；後端只放行 `localhost:8787` 與 GitHub Pages 來源，本機請用 `http://localhost:8787/pixel-plaza/index.html`。
- 寫入（`pixelOfficeUpdate`：狀態、心情、留言）：**測試階段不鎖角色、不跳確認**（上線前恢復：只能改自己登入的角色、第一次寫入要確認）；離線模式（來源未被後端放行）不寫入。
- 投影機開關、道具撿取、便便沖掉**只記在本機**（`localStorage`），不寫後端。
- 角色素材來源：`character-studio/references/`（正、側、背三視圖）→ Codex 補 8 個中間角度（`pixel-plaza/ai-views/`）→ `node pixel-plaza/bake.mjs`（低解析）與 `HD=1 node pixel-plaza/bake.mjs`（高清）烘焙到 `sprites/`、`sprites-hd/`。新造型的三視圖可由 2D 版 `wardrobeFrame()` 擷取（公開服裝 API：`emc-ai-stage-classifier…/api/public/outfits`）。

### 7.x 座位現場（狀態＝場景）
- **加班**：人物腳下一道紫色聚光燈（半透明錐形光柱＋地面光暈，會微微閃動），周圍三團小鬼火（紫色火焰、帶小眼睛）繞著人物飄動。
- **不在座位**（用餐、會議、休假、下班、廁所、出國、公出）：該人的辦公椅與桌上電腦（螢幕、鍵盤、筆電）收起，桌面變灰，桌面上方浮出該狀態的 2D 像素圖示（同 §6 圖示）；恢復在座後全部還原。收起的椅子不能坐。

### 7.y 四樓
- 版面取自 2D 版 `floor4.js`（座標 ×0.5，家具尺寸與五樓相同），整層放在五樓右側（`FX4 = 1400` px 處）：左上電梯、男女廁、木長桌（10 人）與茶水間（含冰箱）、左側五個米黃桌子群、大會議室 H、兩間玻璃辦公室、會議室 F／G。
- 電梯：兩層的電梯都可以點，人物走過去就傳到另一層（鏡頭直接跳過去）；HUD 時鐘旁顯示目前樓層。
- 後端 `meetingRoom` 為 F／G／H 時人物會出現在四樓對應會議室；冰箱庫存依樓層（`floor=4`／`5`）。
