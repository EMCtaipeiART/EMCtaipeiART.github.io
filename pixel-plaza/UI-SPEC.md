# 凱曜多元宇宙 3D 辦公室｜介面與設計規範

> 適用範圍：`pixel-plaza/index.html`（3D 像素辦公室）。**之後新增任何內容、介面、道具，都照這份規範做；改了程式請同步更新這份文件。**
> 資料、座標、後端欄位、部署與排錯請看同資料夾的 [`MAINTENANCE.md`](MAINTENANCE.md)。
> 最後更新：2026-11-01。數值對應 `index.html` 內 `<style>` 的 CSS 變數與常數。
>
> 設計來源：參考 PokéBonk（pokebonk.com）的介面語言——糖果色漸層斜紋、粗描邊 Logo、深色玻璃卡片、圓角膠囊、右上角漸層膠囊按鈕。戰鬥中的介面沒有看到，所以 HUD、圖鑑、等級是依同類遊戲做法自行設計。

## 1. 設計原則

1. **主色系是綠色**（凱曜品牌色）。黃色只當點綴；右上角膠囊按鈕有各自的漸層（見 §5.3），其他地方不要用紅、紫、橘當大面積色塊。
2. **圓、厚、粗描邊**：按鈕、卡片、標籤都是大圓角；文字與 Logo 有粗描邊；按鈕有厚度（底部深色邊）。
3. **玻璃卡片疊在場景上**：HUD 一律用深綠半透明玻璃，不用實心色塊。
4. **內容用繁體中文**，語氣輕鬆；數字與狀態要一眼看懂。
5. **HUD 按鈕圖示是細線條的平面圖示**（見 §5.3），場景裡的狀態／心情圖示才是像素風（§6）；不要用 emoji 當功能圖示（emoji 只可用在語錄、說明文字）。
6. **不遮臉、不遮電腦**：場景裡的物件不得壓在人物臉、電腦、投影機上（見 §8）。
7. **狀態＝場景**：人物的狀態會改變座位現場（見 §7.3），不要另外畫狀態標籤蓋住畫面。

## 2. 色彩（CSS 變數）

| 變數 | 值 | 用途 |
| --- | --- | --- |
| `--c1` | `#8ae99b` | 載入頁漸層起點 |
| `--c2` | `#2fbf57` | 漸層中段、頭像外圈、電梯過場方塊 |
| `--c3` | `#0b6a2b` | 漸層終點 |
| `--ink` | `#0b3d1e` | 描邊、深色文字 |
| `--glass` | `rgba(7,50,28,.84)` | HUD／面板底色（搭配 `backdrop-filter: blur`） |
| `--line` | `rgba(255,255,255,.16)` | 玻璃卡片邊線 |
| `--yellow` | `#ffc733` | 點綴 |
| `--cta1` / `--cta2` | `#43d86c` / `#1aa844` | 主要按鈕漸層 |

- **載入頁底圖**：`linear-gradient(135deg, --c1, --c2 46%, --c3)` 疊 `repeating-linear-gradient(135deg, rgba(255,255,255,.08) 0 16px, transparent 16px 32px)`。
- 場景美術顏色（地板 `#e4eaef`／`#dde4ea`、藍桌 `#1d4ba0`、米黃桌 `#e8c795`）不受上表限制。
- 玻璃面板上文字一律白色；白色面板上用 `--ink`。不要在綠底上放綠字。

## 3. 字體

- 英數與標題 **Fredoka**（500／600／700），中文 **Noto Sans TC**，堆疊 `'Fredoka','Noto Sans TC',system-ui,sans-serif`。
- 一般文字 600；標題、按鈕、數字 700；不用細體。
- 尺寸：Logo `clamp(54px,12vw,96px)`；面板標題 15–19px；HUD 名字 16px（手機 14px）；按鈕 16px；說明 11–12px。
- 粗描邊字（Logo、浮動文字）：`-webkit-text-stroke` ＋ `paint-order: stroke fill`。
- 場景文字標籤（房間名、人物牌子）用 DOM 疊在畫面上，不畫進 3D。

## 4. 形狀、間距、陰影、動態

- 圓角：卡片 22px；面板 18px；按鈕、標籤 999px；格子 11–14px。
- 邊線：玻璃 `2px solid var(--line)`；粗框元件（提示框、泡泡）`2.5–3px solid var(--ink)`。
- 陰影：玻璃 `0 6–8px 14–20px rgba(4,36,18,.3)`；實心提示框用硬陰影 `0 3–6px 0 rgba(...)`。
- 動態：hover 上移 2px；面板淡入；浮動文字 1.3s 上飄；**電梯過場與載入圖示用階梯式（`steps()`）動畫，才有像素感**。新增動態要尊重 `prefers-reduced-motion`。
- 不要旋轉元件（只有載入頁 Logo／卡片）。

## 5. 畫面與元件

### 5.1 載入頁
- 綠色漸層斜紋底 ＋「EMC Office」Logo ＋副標「凱曜設計部 · 3D 像素辦公室」＋**旋轉的像素辦公椅**（`chairIcon()`，階梯式旋轉）＋白色進度條，進度文字只寫「載入角色」（**不顯示 12/12**）。
- 網站嵌入時（`uni-wrap` 背景同色綠漸層），網站自己的載入層已隱藏（`.uni-loading{display:none}`），避免蓋掉這一頁。

### 5.2 進入規則（帳號綁定）
- 身分來源：`localStorage.pixelViewerHandoff`（網站入口寫入，24 小時內有效）或網站登入的 `designRequestEditor*`；名字不分大小寫對應 12 位設計部人物。
- **已登入且有對應人物**：進入就是這個人物（綁定帳號，不能選別人）。進入後若狀態是「下班」，自動改成「在座」並提示（全員下班模式下也一樣；沒進來的人仍顯示下班）。
- **未登入或帳號沒有對應人物**：可以進來參觀（訪客）：滾輪／左鍵拖曳平移畫面、點電梯換看另一層，**不能點人物操作**，左上顯示「訪客・參觀中」。
- 管理者（登入帶 `monitor`）：右上多一顆「切換人物」，點其他人物或桌上狀態圖示可切換成他；一般同仁沒有。
- 只有 `localhost`／`127.0.0.1` 可以用 `?as=名字` 假裝登入（開發測試用，上線網址無效）。

### 5.3 HUD（`#hud`，容器 `pointer-events:none`，按鈕自己接事件）
- **左上玩家卡** `.hp-card`：大頭貼（圓形，黃→綠漸層外圈）、名字、狀態膠囊、經驗條、`Lv.N 圖鑑 x/y`。
- **上中時鐘** `.hp-clock`：台北時間＋星期＋樓層（`・5F`／`・4F`）。
- **右上按鈕列** `.hp-top`（由左到右）：切換人物（僅管理者）→ 角色 → 圖鑑 → 關閉。
- **右下** `.hp-br`：說明（藍紫，偏深，不要太亮）。
- **按鈕樣式（高級平面質感的收合膠囊）**：高 40px（手機 36px）、`border-radius:999px`、**中性深色玻璃底**（`rgba(10,26,20,.72)` ＋ 1px 淡白邊 ＋ blur），**不用大面積漸層或彩色底**；圖示是 22px（手機 20px）的**細單線條圖示**（粗 1.8、圓端點），顏色用各按鈕的強調色 `--ac`；**平常只有圓形＋小圖示，滑鼠移上去（或鍵盤聚焦）往左展開出中文字，邊框變成強調色**；手機沒有 hover，只顯示圖示。圖示與底色必須有明顯對比（例如關閉是深底紅線條 X，不是紅底紅 X）。
- **強調色**（改色只改這幾條 `--ac`）：

| 按鈕 | class | `--ac` |
| --- | --- | --- |
| 角色 | `pk-orange` | `#ffb454` |
| 圖鑑 | `pk-green` | `#62e39a` |
| 說明 | `pk-purple` | `#9db4ff` |
| 關閉 | `pk-red` | `#ff7b7b` |
| 切換人物 | `pk-teal` | `#6fd6e8` |

- **按鈕圖示**：24×24 的內嵌 SVG，定義在 `SVG_ICONS`（`role`、`dex`、`help`、`people`、`close`），用 `svgIcon(名稱, 尺寸)` 輸出，按鈕寫 `<i data-px="名稱"></i>`。**新增按鈕要新增同風格圖示：單線條、簡單、一眼看懂、不要塞滿、不要太多細節**。
- **「關閉」按鈕（`#bClose`）**：嵌在網站元宇宙頁（iframe）時，通知網站關閉（`postMessage {type:'pixelUniverseClose'}`）；手機另開分頁時關掉分頁，關不掉就回網站首頁。`?embed=1` 精簡模式不顯示。
- **手機（≤ 640px）**：玩家卡縮小（隱藏經驗條與等級行）；時鐘改靠左、放在玩家卡下方（`top:78px`），不再和玩家卡重疊；右上按鈕縮成 38px、間距 6px；說明靠右下。
- 投影小視窗 `#proj`：右上，人在會議室且投影機開著才出現；畫面是 1024×576 高清，圓角 8px。
- `?embed=1`（網站設計師面板的小視窗）：隱藏 HUD、標籤與投影視窗，只留場景。

### 5.4 面板（圖鑑、說明）
- 置中玻璃面板，標題列＋右上 ✕；最大寬 640px、最大高 84vh。圖鑑格子 64px，未發現是黑色剪影加「?」。

### 5.5 角色頁面（點右上「角色」開啟；點視窗外、Esc、右上「關閉」都能關）
- 小巧置中玻璃視窗（寬 ≤ 700px）：頂部資訊卡（頭像、位置樓層、名字、狀態膠囊）＋右上「關閉」按鈕（像素叉＋文字，`#cpX`）。
- **完成任何一個動作（心情、留言、音樂、動態、管理者操作）就自動收合視窗。**
- 左欄「心情」：喜怒哀樂 **2×2 大按鈕**＋下方滿版「清除心情」。狀態不在這裡改（見 §5.6）。
- 右欄：「想說的話」（像聊天輸入列，左頭像、中輸入、右綠色圓形送出鈕，60 字，**沒有預覽泡泡**）、「音樂」（貼 Spotify／Apple Music 網址）、「限時動態」（貼照片／GIF／影片，最多 5 則、24 小時）。
- **管理者工具**（可展開，只有管理者帳號看得到）：全員上班／下班、上下班設定、班長處罰。寫入後端時需要管理者權杖，一般同仁即使看到也會被後端拒絕。
- 不放數字磚、統計、說明按鈕、造型、動作。

### 5.6 狀態輪盤（點自己的人物展開）
- 九個狀態排成**圍繞人物的一整圈，順時針，「在座」在正上方**（順序：在座、加班、用餐、會議、休假、下班、廁所、出國、公出），半徑 104px，按鈕 46px 圓形白底黑框，圖示 24px。
- 選「在座」＝人物立刻回座位，並請後端在背景自動判斷（25 秒內不會被後端回的狀態收掉）。
- 輪盤開著時，**第一下點外面只收合輪盤、人物不動，第二下才移動**；人物移動、Esc 也會收合。
- 人物因離開辦公室而隱藏時，點桌上的狀態圖示一樣能展開輪盤。

### 5.7 人物頭上的資訊與名牌
- 頭上一欄由上到下：**一個共用泡泡**（有留言又有音樂時每 3.5 秒輪流顯示；正在播音樂時固定顯示音樂泡泡）→ **圖示列**（限時動態氣泡、心情圖示，不會互相蓋住）。
- 音樂泡泡：▶／⏸ 圓鈕＋跑馬燈歌名；Apple Music 試聽 30 秒，Spotify 在右下角開官方小播放器。
- 限時動態氣泡：2D 風格的像素訊息氣泡，未看過有綠點；點開是 Reels 檢視器（每則 6 秒、左右點切換、按讚、留言）。
- **名牌**：滑鼠移到人物上顯示「名字（狀態）」，腳下一個白底膠囊（不帶圖示）；點人物也只顯示名牌 3 秒。座位旁的離席名牌同樣是白底膠囊、不帶圖示。
- 可以點的東西（人物、椅子、馬桶、冰箱、電梯、投影機、地上道具）滑過時游標變手指。

### 5.8 提示框、電梯過場、冰箱
- `#quote`：置中，底部 92px，白底粗框硬陰影，5.2 秒消失，`z-index:30`（**必須蓋在所有面板上面**）。
- **電梯過場**：綠色（單一顏色 `#2fbf57`）小方塊由下往上**快速堆滿**畫面（方塊約短邊的 1/24、階梯式縮放），中央顯示電梯圖示與目標樓層，換完樓層後方塊由上往下散開，全程約 1.1 秒；**不要用馬賽克配色、不要加格線**。
- 冰箱面板 `#fridgeP`：兩台冰箱各 3×3 食物格（2D 版食物圖集 `fridge/office-foods-v1.webp`），點一格拿一個；走遠或 Esc 自動關門，其他人開冰箱你的畫面門也會打開。

## 6. 狀態與圖示

**出勤狀態圖示一律使用 2D 版原本的像素圖示**（已複製到 `pixel-plaza/assets/`）：
| 狀態 | 圖示來源 |
| --- | --- |
| 下班（power）、廁所（toilet）、出國（plane）、公出（briefcase） | `assets/icons-v3.webp` 3×3 格（順序：太陽、爆炸、水滴、愛心、在座、下班、廁所、出國、公出） |
| 會議（meeting）、用餐（bowl）、休假（calendar） | `assets/icons-status-v4.webp` 三格 |
| 加班（moon） | 程式畫的月牙加星星（`moonIcon()`） |
| **在座（person）** | **程式畫的「黑線框像素椅子」**（`chairIcon()`，會覆蓋 icons-v3 的在座格） |
| 心情：喜（sun）、怒（burst）、哀（drop）、樂（heart） | `icons-v3.webp` 前四格 |
- 取用：`loadIcons()` 後 `iconImg(符號, 尺寸)`；對應表 `symOf`、`moodSym`。
- 九種狀態文字：在座、加班、用餐、會議、休假、下班、廁所、出國、公出；心情文字：喜、怒、哀、樂。心情在頭旁有常駐的動態像素圖示（喜彈、怒抖、哀滴、樂跳），設定時人物跳一下。
- **不要混入第三種圖示風格**；右上按鈕的像素圖示（§5.3）是另一套，只用在 HUD 按鈕。

## 7. 3D 場景規格

### 7.1 基本
- 單位：版面圖 1 px = 0.03 世界單位（`U`）。人物高 2.04，桌子單張寬 3.15。
- 鏡頭：俯視，相對玩家 `(0, 10.9, 12.2)`；**登入者可用滾輪縮放**（倍率 0.5–1.9）；訪客滾輪／左鍵拖曳平移。
- 人物與貼圖道具：**垂直站立**的 billboard，高度乘 `STRETCH` 補償俯視；人物 12 個面向（每 30°）。陰影是 128px 柔邊漸層（不是像素方塊）。
- 家具與房間用 **3D 方塊**做；**所有新物件要有黑色外框**（反向外殼，`OUT_T = 0.04`，放 layer 1；零食用 `outlined()` 描邊，目前 18 原圖像素）。
- 碰撞：人物半徑 0.45；新增家具必須同時登記碰撞矩形（`rects`），通道寬度要 ≥ 1.2 單位。人物卡進碰撞範圍會自動被推出（`unstick`）。
- **點選走路用 A\*尋路**（格子 0.4）繞過牆與家具；點椅子／馬桶走過去自動坐下（沒有 E 鍵）。
- 座位：每張椅子是 `chairSeats`；離開座位（走動）一律解除入座。

### 7.2 玻璃隔間、廁所、投影機
- 玻璃牆 = `WALLS` 的半透明方塊（**厚度 6px**，原本 12px 的一半）；黑色外框只畫「所有牆合起來」的輪廓，**牆與牆接觸、重疊的地方不畫線**；門 = 缺口（寬 60px）。四樓用 `glassWalls(x, y, w, h, doors)` 產生（資料仍寫 12px 厚，建模時才減半）。
- **五樓走道寬度**：廁所／會議室 A／電梯往上移 67px（廁所到辦公桌群的走道 ≥ 2 格＝約 2.6 單位），會議室 B／C／D 與茶水間往下移 33px（辦公桌群到會議室的走道多 1 格）。實作是 `zN()` 分區位移（資料表）＋ `reflow5F()`（建好的 3D 物件）；**新增五樓物件仍照原始座標寫，會自動套用位移；若用絕對座標的資料（標籤、房間範圍）要自己過 `zN()`**。
- 廁所：隔間深寬比照五樓；馬桶可點、可坐、會隨機生成便便。
- 投影機：A 室朝右牆、B/C 朝左牆、D 朝下投地板；四樓 H 朝右、F 朝左、G 朝右。投影畫面平貼白牆（不斜投）；開關與畫面編號全員共用。

### 7.3 座位現場（狀態＝場景）
- **加班**：腳下一道**小而淡**的紫色聚光燈＋三團**明顯**的紫色小鬼火繞著人物飄。
- **不在座位**（用餐、會議、休假、下班、廁所、出國、公出）：該人的椅子與桌上電腦收起、桌面變灰、桌面上浮出該狀態的像素圖示（可點）；**用餐、休假、下班、出國、公出的人物會隱藏**（不在辦公室），會議依行事曆放進對應會議室，廁所坐進馬桶。

### 7.4 四樓與電梯
- 四樓版面取自 2D 版 `floor4.js`（座標 ×0.5，家具尺寸同五樓），放在五樓右邊很遠的地方（`FX4 = 3600` px，視野內看不到五樓）。
- 區域：左上電梯（和五樓同一張電梯圖）、男女廁、10 人木長桌＋茶水間＋兩台冰箱、左側五個米黃桌子群、大會議室 H（六張白桌排 C 字）、**一間**合併的大玻璃辦公室（中間隔一道玻璃牆、正中央留開口，上下左右各一道門）、會議室 F／G。四邊各留約 100px 走廊。
- 四樓固定座位（取自 2D 版）：黎子瑄＝第四組 8 號、余采馨＝第四組 6 號、鄭筱舢＝第四組 7 號、王藍庭＝第五組 5 號。
- **電梯**：登入者走到電梯前就自動換樓層（剛到達要先走開 3 單位才會再次觸發），訪客點電梯換看另一層；後端 `meetingRoom` 為 F／G／H 的人會出現在四樓對應會議室。
- 四樓和五樓有同樣的趣味系統（地上道具、遺落物、便便、投影機）、同樣的冰箱（庫存依樓層）。

## 8. 道具與內容規則

- **大小**：地上掉落物 0.021 世界單位／像素、桌上遺落物 0.012；茶水檯零食八款台灣經典（乖乖、孔雀餅乾、可樂果、義美小泡芙、77 乳加、黑松沙士、麥香紅茶、養樂多），Codex 生成的像素圖放在 `pixel-plaza/snacks/`，外圍描黑色粗框。
- **不得壓住**：隨機出現的物件不可蓋在人物臉／身體前、電腦與投影機上、投影畫面範圍內。新增任何隨機物件都要實作同樣的避讓。
- **隨機規則**：用「時段＋種子」算（所有人同一時段看到一樣）：投影機 6 分鐘、便便 5 分鐘、掉落物 8 分鐘、遺落物 12 分鐘；沿用 `rng()`。**場景（含四樓）全部蓋好才開始算**（`startGameplay()` 在 `buildOffice()` 最後），否則每個人載入的時間點不同會算出不同位置。
- 「已處理」紀錄（撿道具、沖馬桶、撿遺落物、開關投影機）全員共用，寫入後端 `pixelOfficeFun`、從 `funClaims` 讀回。
- 語錄、投影片：沿用 2D 版 `fun.js` 的資料；新增內容要放進同一份資料並給語錄。
- 像素素材用最近鄰放大；Codex 畫的高解析素材用線性濾鏡，兩者不要混在同一個物件。

## 9. 資料與同步（摘要，細節見 MAINTENANCE.md）

- 即時推送：後端 `/ws` 每次有人寫入就通知，收到立刻重讀；輪詢只是備援。
- 位置同步：自己走動時回報，其他人（含訪客）看到平滑走動；**坐在自己座位上不回報**。
- 個人進度（圖鑑、撿到／遺落物／沖馬桶次數，等級由此算出）：存**雲端**（後端 `pixelOfficeProgress`，圖鑑取聯集、次數取較大值），換電腦登入同一帳號讀得回來；本機暫存依帳號分開。
- 離線（來源未被後端放行）時只在畫面上生效，不寫後端。
- 新版上線後，開著的頁面約每分鐘檢查一次，有新版會自動重新載入。
