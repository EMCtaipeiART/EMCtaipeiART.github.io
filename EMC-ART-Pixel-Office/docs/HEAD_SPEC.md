# 頭像製作規範（Pixel Outfit・頭像生成器）

跟服裝一樣的做法：**從現有人物量出規格 → 做成參考圖與提示詞 → 一次生成三組 → 自動檢查 → 完成**。
資料來源是遊戲的頭像圖集 `EMC-ART-Pixel-Office/dist/assets/wardrobe-heads.webp`（v3，五位人物 × 三個角度）。
程式在生成器專案：`lib/head-spec.ts`（提示詞與規格數值）、`lib/head-check.ts`（規格檢查）、`lib/head-reference.ts`（參考圖）。改規格時兩邊一起改。

## 1. 現有五位的頭像（量出來的）

| 人物 | 類型 | 正面 寬×高 | 側面 寬×高 | 背面 寬×高 |
| --- | --- | --- | --- | --- |
| Leona | 黑色長直髮 | 135×130 | 117×132 | 133×124 |
| Amber | 棕色波浪長髮（金色髮尾） | 138×133 | 117×132 | 135×133 |
| Noise | 黑色短髮 | 108×82 | 105×85 | 110×83 |
| Anna | 栗色長波浪髮 | 141×131 | 122×135 | 136×127 |
| Machi | 棕色短髮（挑染） | 106×80 | 105×80 | 114×80 |

- 長髮：寬×高約 117–141 × 124–135（接近正方形）；短髮：約 105–114 × 80–85（橫向）。
- 臉（膚色框）：長髮約 68 寬 × 59 高，下巴在整張頭高的約 65%；髮尾垂到下巴之下。
- 三個角度：**正面 → 朝右側面 → 背面**，下緣（下巴／髮尾）在同一條線上。

## 2. 一定要有 / 一定不能有

- 只有頭與頭髮。**不要**脖子、身體、肩膀、衣服、帽子、眼鏡、耳機（配件由遊戲另外加）。
- 臉：大圓黑眼珠＋一點白色高光、粉色腮紅、細眉、一點鼻點、小微笑；膚色偏暖桃色（#F8B888）。
- 側面是標準右向側臉（一隻眼睛、鼻子、耳朵）；背面只有頭髮（短髮可見耳朵），**不能有臉**。
- 頭髮 2–3 階平塗＋幾條淡色髮絲線，不畫細碎髮絲；描邊深暖黑（#302828），約頭高的 6%。
- 背景透明；三個角度髮色、髮型、分線、髮飾要一致。

## 3. 自動檢查（`HEAD_SPEC`）

| 項目 | 規格 |
| --- | --- |
| 三個角度分開 | 要找到正好 3 個彼此有空白的角度 |
| 高度一致 | 三個角度高度差 ≤ 10%（長髮側面、背面髮尾長度不同，所以比服裝寬鬆） |
| 正面寬高比 | 95%–145% |
| 側面寬高比 | 80%–140% |
| 背面與正面 | 寬度差 ≤ 20% |
| 沒貼邊 | 離畫布邊緣至少 2%，不能被裁切 |

## 4. 流程與費用

- 生成：一次三組供選，**100 點**；不滿意再生成三組 **50 點**（同一個頭像）。跟服裝共用同一份平台幣與帳本。
- 參考照片會先讀成「髮型與膚色」文字再生成（不描述、不辨識人物，也不把照片本身送去畫圖）。
- 完成後存進「我的頭像」；每個角度依輪廓裁切、以最高角度 260 px 為準縮放，存成三張透明 PNG。
- **尚未進元宇宙**：遊戲目前只讀頭像圖集裡的五位人物，要先支援「自訂頭像」（圖集之外的三張圖、下巴位置 s），才能發佈。
